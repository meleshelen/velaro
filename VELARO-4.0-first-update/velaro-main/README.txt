VELARO 3.1 — готова версія з реальними фото

1. Розпакуйте архів.
2. Відкрийте папку velaro-3.1 у VS Code.
3. Натисніть правою кнопкою на index.html → Open with Live Server.
4. Адмін-панель: http://127.0.0.1:5500/admin/

У каталозі 32 товари з фото з вашого архіву.
Ціни, назви, розміри та залишки можна змінювати в адмінці.
Товари адмінки зберігаються у браузері цього комп’ютера.
